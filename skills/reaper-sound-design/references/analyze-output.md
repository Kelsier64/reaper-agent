# 怎麼讀 `R analyze` 的輸出

範例（節錄）：
```
format: 44100 Hz, 2 ch, 24-bit, 42.1 s
peak: -0.1 dBFS   rms: -16.9 dBFS   crest: 16.8 dB
band energy (dB rel. loudest band):
     20-150   Hz   -36.3  ############
    500-1000  Hz    -5.4  ###########################
   1000-2000  Hz     0.0  ##############################
   4000-8000  Hz   -24.2  ##################
strongest peaks: 1319Hz(0dB) 1174Hz(-2dB) 1044Hz(-3dB) ...
timeline (3 s): time  rms dBFS  L-R dB  side/mid dB
      0s    -23.1     0.8       0.3
     21s    -12.1    -0.6     -10.5
     36s    -26.9     1.6       2.3
```

| 欄位 | 意思 | 怎麼用 |
|---|---|---|
| `peak` | 各聲道真實樣本峰值（取最大） | 接近 0 dBFS：limiter 在頂，或可能削波 |
| `rms` | 整體平均響度（各聲道平均） | 比較版本之間的響度；差 1 dB 以內大致聽不出來 |
| `crest` | peak − RMS | 很小（< 8 dB）= 被壓得很扁；很大 = 動態大或有突出的瞬態 |
| `band energy` | 各頻段相對最強頻段的 dB（頻譜用單聲道混音計算） | 確認 EQ/濾波器有沒有照預期作用 |
| `strongest peaks` | 最強的頻譜峰 | 對照音高（440 Hz = A4）或找共振、嗡嗡聲 |
| `timeline` / `rms dBFS` | 每 3 秒的響度 | 漸強漸弱、段落對比、結尾有沒有收乾淨 |
| `timeline` / `L-R dB` | 左減右，**正值 = 偏左** | 檢查 pan automation；整段固定偏一邊通常是效果器不對稱 |
| `timeline` / `side/mid dB` | 立體聲寬度 | 接近 0 = 很寬；−10 以下 = 接近單聲道；正值 = 左右相位相反的成分多，要小心 |

## 注意
- 頻段數字是相對值，不同版本之間比較「形狀」，不要只比單一數字。
- 時間軸是 3 秒一格，短的事件（一個鼓點）會被平均掉。要看細節就 render 一小段再分析。
- 分析的是 render 出來的檔案：如果 render 範圍不對（`--start-bar`/`--end-bar`），結論也會錯。
